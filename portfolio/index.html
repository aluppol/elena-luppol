Основные проекты

PriutBot

Telegram-бот для приюта кошек и собак · 2026

Ведёт посетителя от выбора приюта до консультации, оформления животного и ежедневных отчётов нового хозяина — фото и текст можно прислать в любом порядке. Волонтёры получают уведомления и ведут испытательный срок командами бота, а ежедневная проверка по расписанию сообщает им о просроченных отчётах. Окончательное решение всегда принимает человек.

Java 17 · Spring Boot 3.1 · Spring Data JPA · PostgreSQL · Telegram Bots API

«Доска объявлений» — серверная часть

Командный дипломный проект Skypro · 2023

Серверная часть площадки объявлений по спецификации OpenAPI: регистрация и вход, объявления с изображениями, комментарии, профиль и аватар пользователя, разграничение прав через Spring Security. Команда из четырёх разработчиков; репозиторий проекта ведётся в аккаунте Елены.

Вклад Елены: контроллер, DTO и сервис пользователей; сущности изображений и аватаров; маппинг MapStruct; модульные тесты мапперов, контроллера объявлений и сервиса комментариев — 35 из 88 коммитов проекта.

Spring Boot · Spring Security · Spring Data JPA · PostgreSQL · Liquibase · MapStruct · OpenAPI

OnlineStore

Интернет-магазин на Spring Boot · 2026

Полностью локальное веб-приложение со своей файловой базой данных: вход по имени, каталог из 100 товаров в 19 категориях с постраничным выводом, корзина, которая хранится в базе и переживает перезапуск сервера, оформление заказа со списанием остатков со склада и история заказов.

Java 17 · Spring MVC · Thymeleaf · Spring Data JPA · Hibernate · SQLite

Telegram-бот для приютов — командная версия

Командный проект курса · 2023

Первая, командная реализация бота для приютов кошек и собак: Telegram-интерфейс для посетителей и REST API для животных, клиентов и отчётов.

Вклад Елены: приём и сохранение ежедневных отчётов с фотографиями и сообщения клиентам по отчётам (цепочка контроллер — сервис — репозиторий), исключения для сущностей животных и хозяев, описание контроллеров и Javadoc, тесты сервиса и контроллера — 13 коммитов.

Spring Boot · PostgreSQL · Liquibase · Hibernate · Telegram Bot API · OpenAPI
