# elena-luppol

Site for **elena.luppol.com** — Elena Luppol's page and project portfolio.

- Plain HTML and one shared `styles.css`, no build step and no dependencies.
- Russian at `/` and `/portfolio/`, English at `/en/` and `/en/portfolio/`.
- `fonts/` — PT Serif (ParaType), self-hosted under the SIL Open Font License (`fonts/OFL.txt`).
- `CNAME` — the custom domain.
